## Recent Lessons
- [2026-09-02b: The (row, col) control kills a feature that looked physical](2026-09-02b-the-row-col-control-kills-a-feature-that-looked-physical.md) — the context prior's +0.027 held-out gain was memorized geography. `ctx_log_vel_mean` had 910 unique values across 910 training tiles — a primary key, not a distribution. Two opposite controls pinned it: binning speed into 8 quantiles dropped the gain to +0.001 (coarsen the values, physics dies), while raw `(row, col)` with zero physics scored +0.031 (strip the physics, position wins). `randid` transferred at chance, ruling out plain leakage — the mechanism is spatial *interpolation*. The same run invalidated the holdout that had blessed it: exact-cell `--exclude-ground-from` leaves every training tile's neighbours, so a coordinate model scores 0.955 on the "unseen ground" subset. Also: 3 of 6 context features had exactly 0.0000 importance (constant in training) and one of those was a live untrained code path at scoring time — missing velocity read as evidence of *absence*, crushing P_sar 0.90 → 0.224. Replaced with Bedmap3 as a deterministic hard mask (a mask cannot memorize).
- [2026-09-02: Label confound has a cause; a cleaner map is not a better map](2026-09-02-label-confound-has-a-cause-and-a-cleaner-map-is-not-a-better-map.md) — ice speed alone scored AUC 0.866 on the AlphaEarth labels, and sweeping `--neg-buffer` showed that parameter *creates* the confound (0.866 → exactly 1.000 at buffer 12), because fast uncrevassed ice exists only beside the crevasse field. Speed matching fixed it; SAR then genuinely beat the context floor 0.954 vs 0.843. Then the user's "the prior maps look better" was tested rather than accepted: the prior doubles the map's rank correlation with velocity (0.30→0.61), and on a slow-ice granule it degenerates to a constant that is algebraically identical to a stricter SAR threshold (rank correlation 1.000000, same 168 tiles). Also: the "held-out" granule shared 73% of its ground with training, and the two gates swap strict/loose at P=0.85.
- [2026-09-01: Cross-band domain shift & feature alignment](2026-09-01-cross-band-domain-shift-and-feature-alignment.md) — a 025_091-only gate flagged 73% of an LSAR granule as crevasse (all speckle, Pmax only 0.74 = out-of-distribution, not detection). Fixed with CORAL-lite per-granule feature-moment alignment (73%→5%, real signal untouched). Then my "nodata-boundary" guess for the residual FPs was falsified by a valid-fraction split (only 3-4% partial): 004_048 = speckle residual, 003_064 = oriented-streak artifact firing 2x near the swath edge.
- [2026-08-31: Gate threshold & class overlap](2026-08-31-gate-threshold-class-overlap.md) — "just discard all negatives and keep positives" isn't a threshold choice, it's a wish for a perfect classifier: the classes overlap in RF score, so 100% negative-discard needs keep_p≥0.95 where recall collapses to ~10%. Picked the knee (keep_p=0.65: 90% negs discarded, 73% recall) and named Frangi as the low-prevalence precision backstop.
- [2026-08-30: FFT features and faithful PPB](2026-08-30-fft-features-and-faithful-ppb.md) — "FFT is dead" really meant "my 1D angular *summary* is dead": raw pooled 2D magnitude bins + light despeckle lifted the gate to 0.915 OOF / 0.869 held-out. Hand-rolled PPB had two subtle bugs (amplitude-not-intensity WML estimator; mis-scaled refinement); the reference impl won on AUC (0.924) but was 40x heavier, so PPB was reserved for the ridge stage. Also: a `conda run` job looked hung for 30min — stdout is buffered till exit, check per-worker CPU time.
- [2026-08-29: Classifier feature search and detector drift](2026-08-29-classifier-feature-search-and-detector-drift.md) — FFT angular-ratio classifier feature failed to generalize (same edge-leakage artifact family as the 45° Hough bug); chasing a class-imbalance fix led to visually confirming new "positive" tiles were pure speckle, which uncovered that `build_crevasse_labels.py` never actually passes through the 08-27 session's validated Frangi fix, and that fix's own reference numbers no longer reproduce.
- [2026-08-27: Frangi ridge detector recall](2026-08-27-crevasse-ridge-detection-recall.md) — raw Frangi response amplitude didn't separate real crevasses from speckle; 8x block-averaging (multi-look) before Frangi fixed it where threshold-tuning, dual-polarity combination, and scale-consistency filtering all failed.

## Most Valuable
- [2026-09-02b: The (row, col) control kills a feature that looked physical](2026-09-02b-the-row-col-control-kills-a-feature-that-looked-physical.md) — general pattern: **a feature being physically meaningful says nothing about how the model uses it.** Before trusting any model built on a smooth, gridded, continuous covariate (speed, elevation, surface class), run two controls that point in opposite directions — coarsen the values (does the physics survive?) and replace the feature with raw `(row, col)` (does position alone suffice?). Add a random per-tile id to separate memorization from label leakage: both memorize in-sample, only a *smooth* covariate transfers. Count unique values per training row — near-1.0 means you handed the model a primary key. Treat importance of exactly 0.0000 as "constant in training," and check whether that feature varies at scoring time, because then it is a live untrained code path. Spatial holdouts need a *buffer* in projected metres; exact-cell exclusion is not separation. And when a physical raster genuinely belongs, prefer a deterministic filter over a learned feature — a hard mask cannot memorize.
- [2026-09-02: Label confound has a cause; a cleaner map is not a better map](2026-09-02-label-confound-has-a-cause-and-a-cleaner-map-is-not-a-better-map.md) — general pattern: score any feature you are about to add *alone* first — its solo AUC is the floor the combined model must beat, and a high solo score means you found a confound, not a feature. Trace a confound to the pipeline parameter that produced it and delete that; post-hoc filtering only moves it. Never accept "this looks better" as evidence — correlate the output against the variable you are worried about. And check the IQR of any model applied to a new domain: tree models return a constant outside their training range, which is a relabelled threshold, not a prediction.
- [2026-09-01: Cross-band domain shift & feature alignment](2026-09-01-cross-band-domain-shift-and-feature-alignment.md) — general pattern: a model that fires everywhere but never confidently (low Pmax) is out-of-distribution, not detecting — check the per-scene score distribution before trusting a positive rate. Per-tile normalization removes brightness, not texture-domain shift; single-domain models don't transfer across SAR bands. And never state a false-positive cause you haven't verified by rendering tiles + a statistical split.
- [2026-08-31: Gate threshold & class overlap](2026-08-31-gate-threshold-class-overlap.md) — general pattern: when asked to "discard all negatives, keep all positives," show the class-score overlap — no cut point separates classes a classifier can't; find the knee of the curve and improve separability (features/data) if you need both more discard and more recall.
- [2026-08-27: Frangi ridge detector recall](2026-08-27-crevasse-ridge-detection-recall.md) — general pattern: when every threshold value trades recall for precision at the same rate, check whether the underlying signal separates the classes at all before continuing to tune the threshold.
- [2026-08-29: Classifier feature search and detector drift](2026-08-29-classifier-feature-search-and-detector-drift.md) — general pattern: a surprising aggregate stat (92% positive rate) is a trigger to look at raw examples immediately, not after more feature engineering; "wired into the class" and "reachable from the production script" are different claims, verify both.
- [2026-08-30: FFT features and faithful PPB](2026-08-30-fft-features-and-faithful-ppb.md) — general pattern: "feature X is dead" often means "my hand-crafted *summary* of X is dead" — try handing the model the raw representation before abandoning the signal. And match filter strength to stage cost, not to headline AUC.
